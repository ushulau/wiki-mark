# Command cheat sheet

For wiki-mark 0.5.0. Commands and parameters below match the current implementation.
Examples use generic spaces, pages, and paths.

## Quick start

Run Gradle commands from the project root. On Windows, replace `./gradlew` with
`.\gradlew.bat`. Put task-specific options immediately after the task name.

| Goal | Command |
| --- | --- |
| Preview an import | `./gradlew confluenceImport --page-id=123456 --lossless --verify --preview` |
| Import exact storage | `./gradlew confluenceImport --page-id=123456 --lossless --verify --output=releases/2026.md` |
| Compile pages offline | `./gradlew confluenceCompile` |
| Preview publishing one page | `./gradlew confluencePublish --preview --only=releases/2026.md` |
| Publish one page | `./gradlew confluencePublish --only=releases/2026.md` |
| Explicitly overwrite remote drift | `./gradlew confluencePublish --only=releases/2026.md --force` |
| Render selected diagrams | `./gradlew confluenceRenderDiagrams --only=architecture --only=workflow` |
| Reset legacy change tracking | `./gradlew confluenceResetState` |
| Build and run all tests | `./gradlew build` |

## Gradle commands

### `confluenceImport`

Fetch one page and create local sources. Does not publish or modify Confluence.
Choose exactly one of `--page-id` and `--page-url`.

| Parameter | Default | Short explanation |
| --- | --- | --- |
| `--lossless` | Off | Preserve raw storage instead of converting it to Markdown. |
| `--no-baseline` | Off | Do not record a publish baseline for this import. |
| `--output=PATH` | Generated title-and-ID filename | Relative `.md` path beneath `confluence.pagesDir`. |
| `--overwrite` | Off | Replace files generated by this import. |
| `--page-id=ID` | Required selector | Numeric source page ID. |
| `--page-url=URL` | Alternative selector | Same-site `/pages/ID/...` or `viewpage.action?pageId=ID` URL. |
| `--parent=TITLE` | Source ancestors | Replace ancestry; repeat outermost first. Requires `--lossless`. |
| `--parent=` | — | Clear source ancestry to target a space root. Requires `--lossless`. |
| `--preview` | Off | Print content, paths, and warnings; no writes or asset downloads. |
| `--space=KEY` | Source space | Retarget space header. Requires `--lossless`. |
| `--title=TITLE` | Source title | Retarget title header. Requires `--lossless`. |
| `--verify` | Off | Recompile before writing and check exact source storage equality. Requires `--lossless`. |

```sh
./gradlew confluenceImport --page-id=123456 --lossless --verify --space=DEMO --parent="Guides" --parent="Releases" --title="Example release" --output=releases/2026.md
./gradlew confluenceImport --page-id=123456 --lossless --overwrite --preview
```

Preview checks output collisions too; add `--overwrite` to preview replacing an
existing import. Lossless files retain original attachment names. A provenance
manifest is written beside the document; a storage snapshot is added when warnings
occur. Verification offsets are UTF-16 character offsets.

A successful non-preview lossless import that targets the source page also
records a publish baseline under `.gradle/confluence-publish/baselines`, so the
next publish sees no drift. No baseline is written for previews, retargeted
imports, lossy Markdown imports, or with `--no-baseline`; import always prints
which case applied. `confluenceResetState` keeps baselines. Routine:
import (or re-import to refresh), edit locally, publish — no `--force` needed
unless the wiki moved meanwhile.

### `confluenceCompile`

Compile discovered pages to `build/confluence/storage`. No task-specific flags,
network connection, or token are needed. Runs diagram rendering first; diagram
conversion is disabled by default.

```sh
./gradlew confluenceCompile
./gradlew confluenceCompile -x confluenceRenderDiagrams --rerun-tasks
```

Configure inputs using `pagesDir` and `pageIncludes`; configure output with the
`confluenceCompile.outputDir` task property. Compile does not have `--only`.

### `confluencePublish`

Run render and compile, then publish selected pages. Requires connection settings
and a token, including for preview.

| Parameter | Default | Short explanation |
| --- | --- | --- |
| `--changed` | Off / `onlyChanged` setting | Compatibility option; all selected pages are still checked remotely for drift. |
| `--force` | Off | Authorize replacing remote drift or an unknown baseline. |
| `--only=PATH` | All matching pages | Select a file relative to `pagesDir`; repeat for several files. Takes precedence over `--changed`. |
| `--preview` | Off | Read remote state and print proposed storage/drift without remote or baseline writes. |

```sh
./gradlew confluencePublish --preview --only=guide.md --only=reference.md
./gradlew confluencePublish --changed
./gradlew confluencePublish --only=guide.md --force
```

**Behavior to remember:**

- Local-only edits publish silently. Remote drift or an unknown baseline requires
  console confirmation; without a console, the command fails and requires `--force`.
- A lossless import records the baseline, so editing an import and publishing
  needs no `--force`. Re-import after `--force` to refresh a stale baseline.
- Conflict output names the remote and baseline versions, the last editor and
  time, and a unified diff; server-side normalization (macro IDs) can cause a
  one-time remote-only drift notice — republish with `--force` to refresh.
- Identical storage skips all remote writes, including labels and attachments.
  An attachment-only or label-only change requires a body change to publish.
- `--force` does not bypass equality skipping or concurrent HTTP 409 conflicts.
- Publish preview still runs dependencies that may write local compiled files or
  diagram outputs. `--only` does not narrow those dependencies.
- Gradle `--dry-run` lists scheduled tasks without running them. Use task
  `--preview` to inspect live publishing behavior.

### `confluenceRenderDiagrams`

Render `.mmd` files using the configured Mermaid container. Enable PNG and/or SVG
conversion in `confluence.diagrams` first.

| Parameter | Default | Short explanation |
| --- | --- | --- |
| `--only=NAME` | All diagrams | Render selected diagram names; repeatable, `.mmd` suffix optional. |

```sh
./gradlew confluenceRenderDiagrams --only=architecture --only=workflow.mmd
```

### `confluenceResetState`

```sh
./gradlew confluenceResetState
```

No task-specific parameters. Deletes legacy page/diagram hash state. Preserves
successful-publish baselines used for drift detection. Not needed for a newly
imported page. `clean` does not remove `.gradle` state.

## Gradle connection and configuration

Connection and rendering settings are **DSL properties**, not arbitrary task flags.
For example, publishing has no `--base-url` option; set `confluence.baseUrl`.

```groovy
confluence {
  baseUrl = 'https://wiki.example.com'
  pagesDir = layout.projectDirectory.dir('documentation/wiki')
  pageIncludes = ['releases/[0-9]*.md', 'guides/**/*.md']
  // username = 'example-user' // Basic auth; omit for Bearer auth
  diagrams {
    convertToPng = true
    containerEngine = 'docker'
  }
}

tasks.named('confluenceCompile') {
  outputDir = layout.buildDirectory.dir('wiki-storage')
}
```

Token resolution: `confluence.authToken` override, otherwise Gradle project
property `confluence.token`, otherwise `CONFLUENCE_TOKEN`. A project property can
be supplied in Gradle properties or as `-Pconfluence.token=TOKEN`. Prefer the
environment or user Gradle properties for secrets.

```powershell
# PowerShell: reuse a token already available in the environment.
.\gradlew.bat confluencePublish --preview
```

### All `confluence { ... }` properties

Empty strings mean unset. Page metadata can override applicable fallback settings.

| Property | Type / default | Purpose |
|---|---|---|
| `appendLabels` | Boolean, `false` | Add labels without removing existing ones. Default replaces labels, including clearing them for pages without labels. |
| `attachReferenced` | Boolean, `false` | Also upload local files referenced by links. Local images are collected without this flag. |
| `authToken` | String, Gradle `confluence.token` then `CONFLUENCE_TOKEN` | Required for publishing and importing, including preview. |
| `baseUrl` | String, `''` | Required for publishing and importing, including preview. |
| `changesOnly` | Boolean, `false` | Compatibility flag; exact storage equality always skips remote writes. |
| `contentAppearance` | String, `''` | `full-width`, `fixed`, or `default`; header wins, otherwise `full-width`. |
| `continueOnError` | Boolean, `false` | Process remaining pages after a failure; task still fails if any page failed. |
| `diagrams` | Nested block | The rendering settings below. |
| `dropH1` | Boolean, `false` | Omit the first H1 from rendered content. |
| `imageAlign` | String, `''` | `left`, `center`, or `right`; page header wins. |
| `imageHeight` | String, `''` | Max pixel height cap for local PNG/SVG images, scaled proportionally; page header wins. Only the binding dimension is written to the page. |
| `imageWidth` | String, `''` | Max pixel width cap for local PNG/SVG images, scaled proportionally; page header wins. Only the binding dimension is written to the page. |
| `insecureSkipTlsVerify` | Boolean, `false` | Skip certificate and hostname verification; logs a warning. For testing only. |
| `minorEdit` | Boolean, `false` | Mark page updates as minor edits. |
| `onlyChanged` | Boolean, `false` | Compatibility flag; remotely check every selected page for drift; `--only` takes precedence. |
| `pageIncludes` | List of strings, `['**/*.md']` | Paths/globs relative to `pagesDir`, deduplicated and sorted. |
| `pagesDir` | Directory, `documentation/wiki` | Base directory for page discovery. |
| `parents` | List of strings, `[]` | Prepend a parent chain to page-declared parents. Missing parents are created during publish. |
| `parentsFromPath` | Boolean, `false` | Derive parent titles from directories when the page has no explicit parents. Index/README pages represent their own directory. |
| `parentsFromPathRoot` | String, `''` | Root for directory-derived parents; empty uses `pagesDir`. Prefer an absolute path. |
| `space` | String, `''` | Fallback space key for pages. |
| `titleAppendHash` | Boolean, `false` | Append a short hash of parents, space, and title to the resolved title. |
| `titleFromFilename` | Boolean, `false` | Derive a missing title from the filename, replacing hyphens/underscores with spaces and title-casing. Mutually exclusive with `titleFromH1`. |
| `titleFromH1` | Boolean, `false` | Derive a missing title from the first H1 outside code fences. |
| `trustStore` | File, unset | Extra trust store augmenting the JVM's default store. |
| `trustStorePassword` | String, `''` | Password for the extra trust store. |
| `username` | String, `''` | Nonempty selects Basic auth; empty selects Bearer auth. |
| `verifyOnCheck` | Boolean, `false` | Wire compile into `check` if a lifecycle plugin providing `check` is applied. |
| `versionMessage` | String, `''` | Message sent with page updates. |

### All `confluence { diagrams { ... } }` properties

| Property | Type / default | Purpose |
|---|---|---|
| `background` | String, `white` | Nonblank Mermaid CLI background (`-b`). |
| `containerEngine` | String, `docker` | `docker` or `podman`. |
| `containerImage` | String, `minlag/mermaid-cli:12.0.1` | Mermaid CLI container image. |
| `convertToPng` | Boolean, `false` | Generate PNG images next to the sources. |
| `convertToSvg` | Boolean, `false` | Generate SVG images next to the sources. Both formats may be enabled. |
| `extraRunArgs` | List of strings, `[]` for Docker, `['--userns=keep-id']` for Podman | Engine flags before the image; an explicit list replaces the default. |
| `mermaidJson` | String, built-in JSON | Mermaid config contents (`-c`), not a file path. |
| `puppeteerJson` | String, built-in JSON | Puppeteer config contents (`-p`), not a file path. |
| `scale` | Integer, `2` | Positive Mermaid CLI scale (`-s`). |
| `sourceDir` | Directory, `pagesDir/diagrams` | Directory containing `.mmd` files. |

`mermaidJson` and `puppeteerJson` contain JSON text, not file paths. Their built-in
JSON defaults are in the [configuration reference](../README.md#complete-configuration-reference).

Task properties additionally include `confluenceCompile.outputDir`,
`confluenceImport.wikiDir`, and the properties corresponding to task options
(`pageId`, `pageUrl`, `output`, `parents`, `lossless`, `verify`, `overwrite`,
`preview`, `space`, `title`, `force`, `changed`, `onlyFiles`, `onlyDiagrams`).
They belong to their respective tasks, not all to the extension. Gradle import
normally follows `pagesDir`; it has no `--wiki-dir` command-line option.

## CLI launcher

`mark` below is shorthand for the Java entry point; this repository does not
install a `mark` executable. Build the jars first:

```powershell
.\gradlew.bat :cli:jar :core:jar
java -cp "cli/build/libs/cli-0.5.0.jar;core/build/libs/core-0.5.0.jar" dev.vspex.wiki.mark.cli.Main --help
```

On Unix use `:` instead of `;` between classpath entries. Replace `mark` in the
examples with that Java invocation, or create a local shell wrapper.

### `mark sync` (also `mark`)

```sh
mark sync --files 'documentation/wiki/**/*.md' --compile-only
mark sync --files 'documentation/wiki/**/*.md' --base-url https://wiki.example.com --dry-run
mark sync --files 'documentation/wiki/guide.md' --base-url https://wiki.example.com --force
mark --help
mark --version
```

`sync` is optional. Quote globs. Boolean flags take no value; do not use
`--force=true`. Value flags accept `--name VALUE` or `--name=VALUE`.

| Parameter | Short explanation |
| --- | --- |
| `--append-labels` | Add labels without removing existing ones. |
| `--attach-referenced` | Upload local files referenced by links; local images are discovered automatically. |
| `--changes-only` | Compatibility flag; exact storage matches always skip remote writes. |
| `--ci` | Allow file patterns that match nothing. |
| `--compile-only` | Print storage offline; no credentials required. |
| `--content-appearance VALUE` | `full-width`, `fixed`, or `default`. |
| `--continue-on-error` | Process remaining files after a failure; still return failure overall. |
| `--drop-h1` | Omit the first H1 from normal Markdown rendering. |
| `--dry-run` | Fetch remote state and print proposed storage/drift; write nothing. |
| `--files PATTERN...`, `-f` | Required file selection; one or more paths/globs. |
| `--force` | Explicitly authorize replacing drift; does not bypass concurrent version conflicts. |
| `--help`, `-h` | Show help. |
| `--image-align VALUE` | `left`, `center`, or `right`; page header wins. |
| `--image-height PX` | Maximum image height; page header wins. |
| `--image-width PX` | Maximum image width; page header wins. |
| `--log-level LEVEL` | `debug`, `info`, or `warning`; default `info`. |
| `--minor-edit` | Suppress update notifications. |
| `--parents CHAIN` | Prepend parent titles, such as `Guides/Releases`. |
| `--parents-delimiter CHAR` | Parent-chain separator; default `/`. |
| `--parents-from-path` | Derive parents from directories when not explicitly declared. |
| `--parents-from-path-root PATH` | Root for directory-derived parents; otherwise inferred from file patterns. |
| `--space KEY` | Default space when a document has none. |
| `--strip-linebreaks` | Accepted compatibility flag; no effect. |
| `--title-append-generated-hash` | Append a short hash of parents, space, and title. |
| `--title-from-filename` | Derive a missing title from the filename; incompatible with `--title-from-h1`. |
| `--title-from-h1` | Derive a missing title from the leading H1. |
| `--version` | Print CLI version. |
| `--version-message TEXT` | Publish message; the storage hash tag is added automatically. |

Also accepts every connection option in the shared CLI table below. Storage
wrappers bypass Markdown formatting options to preserve their original bytes.

### `mark import`

```sh
mark import --page-id 123456 --base-url https://wiki.example.com --lossless --verify --preview
mark import --page-id 123456 --base-url https://wiki.example.com --lossless --verify --wiki-dir documentation/wiki --output releases/2026.md
mark import --page-id 123456 --base-url https://wiki.example.com --lossless --space DEMO --parent Guides --title "Example copy"
mark import --help
```

Accepts the same import options described in the Gradle import table, with
`--option VALUE` or `--option=VALUE` syntax, plus:

| Parameter | Short explanation |
| --- | --- |
| `--wiki-dir DIR` | Wiki root within the current project; default `documents/wiki`. |
| `--no-baseline` | Do not record a publish baseline for this import. |
| `--help`, `-h` | Show import help. |

Use singular, repeatable `--parent` for import; sync uses `--parents` for a chain.
Import uses `--preview`; CLI sync uses `--dry-run`. `--overwrite` replaces local
import files; `--force` is a publish option and is not accepted by import.

### Shared CLI connection options

These apply to both `mark sync` and `mark import`.

| Parameter | Short explanation |
| --- | --- |
| `--base-url URL`, `-b` | Confluence URL including any context path, such as `/wiki`. Required for network operations. |
| `--insecure-skip-tls-verify` | Disable certificate verification; testing only. |
| `--password TOKEN`, `-p` | API token; overrides `CONFLUENCE_TOKEN`. |
| `--trust-store PATH` | Additional JVM trust store. |
| `--trust-store-password TEXT` | Password for that trust store. |
| `--username NAME`, `-u` | Basic-auth username; omit to use Bearer authentication. |

The CLI does not read Gradle's `confluence.token` property. It uses the current
working directory as its project root. Gradle defaults to `documentation/wiki`;
CLI import defaults to `documents/wiki` unless `--wiki-dir` is specified.

| `./gradlew check` | Run checks; does not publish to Confluence. |
| `./gradlew clean` | Remove build outputs; keep `.gradle` state. |
| `./gradlew spotlessApply` | Format Java source. |
| `./gradlew :core:test` | Core unit tests. |

For behavior and recovery details, see the [import/publish guide](confluence-import.md).

## Merge publishing

| Parameter | Commands | Short explanation |
| --- | --- | --- |
| `--merge` | `confluencePublish`, CLI sync | Combine independent body edits using saved local/remote snapshots; fail on conflict. |
| `--merge --preview` | `confluencePublish` | Show the merged candidate without remote or baseline writes. |
| `--merge --dry-run` | CLI sync | Preview the merge without writes. |

`--merge` cannot be combined with `--force` or CLI compile-only mode. Existing-page
merges preserve auxiliary resources; missing attachment uploads require separate reconciliation.
